# E-Commerce Sales Analysis Dashboard | Microsoft Excel

## Project Overview
This project focuses on analyzing e-commerce sales data using Microsoft Excel to identify sales trends, customer purchasing behavior, and regional performance. An interactive dashboard was developed using PivotTables, PivotCharts, KPI cards, and dynamic slicers.

## Dashboard Preview
The dashboard provides a consolidated view of sales and customer performance, allowing users to explore the data through interactive filters.

## Key Performance Indicators (KPIs)
- Total Customers
- Total Orders
- One-Time Customers
- Repeat Customers
- Total Quantity Sold
- Average Delivery Days
- Average Customer Rating

## Key Analysis
- **Product Category Analysis:** Compared revenue across Beauty, Clothing, Electronics, and Home categories.
- **Regional Sales Analysis:** Analyzed revenue and quantity sold across East, North, South, and West regions.
- **Customer Analysis:** Examined one-time and repeat customers.
- **Payment Method Analysis:** Compared revenue and order counts across Card, Cash on Delivery (COD), and Wallet payments.
- **Customer Satisfaction:** Compared average customer ratings by product category.
- **Discount Analysis:** Examined discount distribution across product categories.
- **Sales Trend Analysis:** Visualized revenue trends over time.

## Interactive Features
- Dynamic **Region Slicer** to filter dashboard results by region.
- Dynamic **Month Slicer** to explore monthly sales performance.
- Interactive PivotCharts and KPI cards for easier data exploration.

## Tools & Skills Used
- Microsoft Excel
- PivotTables and PivotCharts
- Slicers and interactive dashboards
- Excel formulas and KPI calculations
- Data analysis and visualization
- Business insights and reporting

## Business Objectives
- Identify top revenue-generating product categories.
- Compare regional sales and quantity performance.
- Understand customer purchasing patterns.
- Evaluate delivery performance and customer ratings.
- Support business decisions through interactive sales reporting.

## Key Learning Outcomes

## Conclusion
This project demonstrates the use of Microsoft Excel to transform raw e-commerce data into an interactive dashboard for sales monitoring and business performance analysis.
